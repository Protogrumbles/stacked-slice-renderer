Stacked-Slice Renderer

Ocean + islands rendered as stacked offset horizontal pixel layers, with parallax — and now flyable. Mouse steers, click rolls, hold mouse/W for thrust, Shift afterburner, ↑ dives, ↓ climbs, Space cycles the camera (chase → overhead → cockpit), [ / ] change pixel size. This is the UI8 fly-demo technique, explained in TECHNICAL.md — stacked slices, not Mode 7.

Single file, zero network requests. Open this file in any browser — nothing is fetched. The slice maths is pure JavaScript and is tested headlessly by test_slice_math.js (Node, no dependencies).
